About Me

I'm Fahid A. Khan, a Software Design Engineer at Treon in Tampere, Finland, where I've been building platform software and backend systems for industrial IoT since 2021. I specialize in backend development, cloud infrastructure, DevOps, and intelligent automation.

With a Master's degree in Software, Web & Cloud Engineering and a Bachelor's in Computer Software Engineering — both from Tampere University — I bring a strong theoretical foundation paired with 4+ years of hands-on industry experience. I'm passionate about solving real-world problems through clean architecture, reliable pipelines, and automation.

At Treon, I work across the full platform stack: building Python tools for testing and integration, managing CI/CD pipelines with Jenkins, automating infrastructure with Docker and Ansible, and integrating with Azure IoT Hub. I use Grafana for monitoring, shell scripts for system automation, and Robot Framework for comprehensive test coverage across Linux environments.

I consider myself a problem solver first and a specialist second. I prefer learning by doing and believe in building software that is maintainable, observable, and secure. Whether it's designing a new microservice, setting up a deployment pipeline, or automating a repetitive business process with AI, I focus on delivering value efficiently.
