About Me

Hey, I'm Fahid. I build backend systems, wrangle cloud infrastructure, and automate everything that shouldn't be done twice. Based in Tampere, Finland, where the winters are long and the coffee consumption is... professional-grade.

I've spent the last 5+ years working on industrial IoT platforms. The kind where thousands of sensors are yelling data at your servers 24/7 and your job is to make sure nothing catches fire (figuratively, mostly). My days involve writing Python, staring at Jenkins logs, and occasionally having calm conversations with Terraform about why it wants to destroy a production database.

I got into this through a Master's in Software, Web & Cloud Engineering and a Bachelor's in Computer Software Engineering, both from Tampere University. Somewhere along the way I also picked up an Azure DevOps certification (AZ-400) because apparently I enjoy exams. The degrees gave me the theory; the real education was the first time a deployment went sideways at 4 PM on a Friday.

My approach is simple: if I have to do something more than twice, I automate it. If it can break silently, I add monitoring. If the documentation doesn't exist, I write it (and then forget where I saved it, still working on that part). I care about code that's readable six months later, pipelines that don't need babysitting, and infrastructure you can actually reason about.

What I Specialise In

Cloud Infrastructure

Azure and AWS are where most of my cloud work happens. IoT Hub for devices, EKS and ECS for container orchestration, Terraform so I don't have to click around any portals, and Grafana so we can actually see what's happening.

Azure AWS Kubernetes Terraform Grafana

DevOps & CI/CD
